About the Project

Pokédex Explorer is a web application I created that allows users to explore different Pokémon and learn more about them. The project uses the PokéAPI to collect Pokémon information and display it on a webpage in an organized and user-friendly way.

Users can view the first 20 Pokémon, search for specific Pokémon by name or Pokédex number, and see information such as their images, types, height, and weight.

Features

Displays 20 Pokémon when the user clicks the Load 20 Pokémon button.

Allows users to search for Pokémon by name or Pokédex number.

Displays Pokémon images and ID numbers.

Shows each Pokémon's type, height, and weight.

Includes a Show All button to bring back the original collection.

Displays error messages if something goes wrong while loading or searching.

Works on both desktop and mobile devices.
